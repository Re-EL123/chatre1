Integrations

          

            Connect your own GitHub, Vercel, Supabase, or Firebase account. Tokens are encrypted server-side and used only by the agent for your requests — never shown again after save.
          

          
          
          
          

            
            
            
          

          

          

        

        

          
Admin service key (RBAC)

          

          

            Admin-only. Used by the desktop companion / ops — not for chatting or listing your threads.
            Sign in as a user for normal workspaces. Optional admin users: set CHATRE_ADMIN_EMAILS on the API.
          

        

        

          
Agent autonomy

          
          
          

          
          

            Autopilot auto-extends budget twice, runs one critic repair, and skips plan approval.
            High-risk tools (desktop_exec, git_push) still ask. Named agents (build/plan/explore) enforce allow/ask/deny permissions.
          

        

        

          
Custom agents

          

            Generate a specialized agent (OpenCode-style). It is saved to your account and appears in the agent picker.
